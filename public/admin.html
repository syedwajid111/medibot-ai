Database & automatic backups

  • All data is stored in Neon PostgreSQL (Vercel → medibot-ai → Storage → Neon → Open in Neon to browse tables or run SQL).
  • Neon keeps a restore history – you can restore the database to an earlier point in time from the Neon console (Backup & Restore).
  • Download a JSON backup here before your viva or any big change.
